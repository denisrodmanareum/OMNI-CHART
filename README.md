# AngelAreum · Futures Terminal

바이낸스 USDT 무기한 공개 시세를 사용하는 선물 차트·판단 보조 도구입니다.
기존 OMNI 페이지를 AngelAreum으로 개편했습니다. 배포 주소는 유지합니다.

**자동 주문은 없으며 수익성을 보장하지 않습니다.**

## 실행과 검증

이 디렉터리에서 실행합니다. Node 의존성 설치나 빌드는 필요하지 않습니다.

```sh
python -m http.server 8765 --bind 127.0.0.1
node --test tests/*.test.cjs
```

브라우저에서 `http://127.0.0.1:8765`를 엽니다. 실행에는 인터넷과 Binance 공개 API 접근이 필요합니다.
배포할 때는 `index.html`만 복사하지 말고 **이 디렉터리의 모든 실행 파일과 vendor를 함께** 배포해야 합니다.

## 차트 조작

- **Auto / A**: 현재 보이는 캔들의 고가·저가에 가격축을 자동으로 맞춥니다. 먼 EMA·추세선이 캔들을 압축하지 않습니다. 시간축 이동·확대에도 적용합니다.
- **가격축 드래그**: 수동 가격축 조절로 전환합니다. Auto를 다시 누르면 자동 높이 맞춤으로 돌아옵니다.
- **최신 / L**: 최신 캔들로 이동하며 Auto를 켭니다.
- **수평선 / H**: 차트를 눌러 내 수평선을 추가합니다. 패널의 가격 입력도 지원합니다.
- **선 삭제**: 차트에서 내 수평선 가까이를 눌러 삭제합니다. 패널에서 개별·전체 삭제도 가능하고, 15초 안에 실행 취소할 수 있습니다. 자동 분석선은 이 도구로 삭제하지 않습니다.
- **Esc**: 그리기·삭제 모드와 레이어 메뉴를 닫습니다.
- **레이어**: 집중 / 구조 / 전체 프리셋과 개별 체크박스를 지원합니다. 표시만 바꾸며 신호 계산에는 영향을 주지 않습니다.
- **신호 기록**: 과거 위치로 이동합니다. 현재 주기의 조회 범위 밖이면 해당 신호의 4H/일봉으로 전환합니다. 판단 패널은 계속 최신 분석이므로 과거 시점 재생으로 해석하지 않습니다.

## 급변동(급락·급등)과 반등·반락

- 현재 차트 주기의 **마감 봉**에서 몸통이 직전 ATR(14)의 2.5배 이상이거나 3봉 누적 이동이 4배 이상이면 급락·급등으로 표시합니다.
- 같은 방향이 이어지면 한 구간으로 묶습니다. 구간 폭의 50%를 종가로 되돌리거나 반대 방향 급변동 봉이 나오면 반등·반락으로 확정합니다. 12봉 동안 되돌림이 없으면 구간을 종료합니다.
- 구간이 진행 중이면 38% / 50% / 62% 되돌림 기준선을 차트와 패널에 표시하고, 현재 판단 띠에 변동성 확대 경고를 붙입니다. 4H 상태는 차트 주기와 무관하게 함께 표시합니다.
- 진행 중 봉이 기준을 넘거나 구간의 50% 되돌림에 닿으면 페이지 안 알림(소리·기록)을 봉·구간마다 한 번 보냅니다. 마감으로 확정된 이벤트도 따로 알립니다.
- 급변동 표시는 변동성 경고이며 방향·진입 신호가 아닙니다. 기존 일봉·4H 신호 규칙과 R 기록에는 영향을 주지 않습니다.
- 레이어에 급변동(기본 켜짐), 볼린저 20·2σ, RSI 14(차트 하단)를 추가했습니다. 시간봉에 1분·5분을 추가했습니다.
- MACD 12·26·9(차트 하단, RSI와 함께 켜면 위로 쌓임)와 세션 VWAP(KST 09:00 초기화, 1시간봉 이하) 레이어를 추가했습니다.
- 강제 청산: `@forceOrder` 스트림으로 **접속 이후 수신분만** 롱·숏 청산 금액을 집계합니다. 거래소가 초당 최신 1건만 보내므로 전체 청산액이 아닌 참고값입니다.
- **추세선 / T**: 차트에서 두 점을 차례로 눌러 내 추세선을 추가합니다. 최신 봉까지 연장 표시하며 종목별로 최대 20개 저장합니다. 선 삭제 모드나 패널 목록에서 삭제·실행 취소할 수 있습니다. 두 번째 점은 0.5초 이상 간격을 두고 누릅니다.

## 표시 데이터

- 롱/숏 계정 비율, 테이커 매수/매도 비율, OI 24시간 변화 (5분 주기 조회 · 실패 시 해당 행만 숨김 · 방향 신호 아님)

- 마지막 체결가, OHLC, 24시간 가격 변화, 거래량
- 마크가격·지수가격·괴리율
- 펀딩비, 거래소가 제공한 다음 정산 시각과 카운트다운 (8시간 고정 가정 없음)
- 현재 미결제약정 OI, 마크가격으로 환산한 대략적 USDT 명목액
- 24시간 거래대금·고가·저가, 최우선 매수/매도 호가·스프레드
- 마감된 일봉·4H 방향과 계획, 지지·저항, 추세선, 피보나치, 후보 구간, SQ

체결가·현재가 대비 손절 거리 등은 수신 틱에 맞춰 제한된 빈도로 갱신합니다.
소켓 틱이 8초 이상 없으면 최근 선물 캔들 2개를 5초마다 REST로 보완하며, 수신 방식과 경과 시간을 표시합니다. 늦은 REST 응답은 더 최신 소켓 틱을 덮어쓰지 못합니다.
시세가 30초 이상 갱신되지 않으면 현재 판단도 `시세 확인`으로 바뀝니다. EMA는 최신 봉을 함께 갱신하고, 교차선을 가리키는 동안 OHLC는 선택한 봉의 값을 유지합니다.
선물 지표는 30초마다, 관심 종목 가격도 가벼운 가격 API로 30초마다 갱신합니다. 관심 종목의 캔들 분석은 최초 조회·새 종목 추가·4H 마감 뒤에만 갱신하며, 탭 복귀·일반 새로고침에서는 같은 4H 캐시를 재사용합니다. 시각과 실패 상태를 표시합니다.
관심 종목의 비선택 가격은 조회 시점 스냅샷입니다. OI와 펀딩비를 단독 방향 신호로 취급하지 않습니다.

## 정합성 및 신호 규칙

모든 시세·분석·실시간 스트림은 Binance **USDT 무기한**으로 고정합니다. 선물 장애 때 현물로 자동 대체하지 않습니다.
종목·시간봉 전환 시 이전 요청과 소켓을 폐기합니다. 늦게 도착한 응답·오류·틱은 무시하고, 실패하면 이전 캔들을 지웁니다.
정기 분석 갱신은 기존 소켓·차트·가격 알림을 유지한 채 진행합니다. 실패하면 기존 확정 결과에 갱신 지연을 표시하고 10초부터 최대 2분 간격으로 재시도합니다. 거래소 제한이 있으면 그 대기 시간을 우선합니다. 연결이 지연되거나 재연결될 때 REST로 캔들을 다시 받아 누락을 복구합니다. 누락·중복·비정상 캔들은 오류로 노출합니다.
이번 주가 실제 종료되기 전에는 주봉을 확정 상위 레벨 계산에 넣지 않습니다. 신호의 정확한 진입 4H 봉·보유 구간·만료 시점이 조회 범위에 없으면 `범위 밖`으로 표시하고 진입가와 R을 생성하거나 집계하지 않습니다.

일봉 모멘텀 전환과 4H 전환선/기준선 방향 변경의 기존 규칙을 유지합니다.
마감된 봉만 신호를 만들며, 다음 봉 시가 기준 2 ATR 손절(최대 10%), 2R 목표, 72시간 만료입니다.
동시 반대 신호는 제외하고, 같은 4H 봉에서 손절과 목표가 함께 닿으면 손절을 우선합니다.
가격 도달과 결과 확정은 구분하며, 결과 판정은 4H 마감 기준입니다.

계획에는 진입 기준가와 현재 위치(R)를 함께 표시합니다. 가격 표시와 새 수평선·알림은 거래소 `PRICE_FILTER.tickSize`를 따릅니다. ATR 분석과 R은 원래 연속 가격 계산값을 유지합니다.

각 모듈의 R 기록은 수수료·펀딩·슬리피지를 제외한 독립 가상 계획 기록입니다. 합산 계좌 수익률·체결 검증·전략 수익성 검증이 아닙니다.

## 갱신 중 화면 안정성과 요청 제한

- 과거 차트는 논리 인덱스 대신 절대 시각 범위를 복원하므로 데이터 창이 한 봉 이동해도 과거 위치를 유지합니다.
- 가격 입력 카드의 DOM을 유지해 주기 갱신 중 입력값·포커스·커서가 떨어지지 않게 합니다.
- 근접 지지·저항의 가격축 캡션만 묶습니다. 실제 가격선 좌표는 유지하며 가격 구조 카드에서 각 묶음의 범위와 근거를 확인할 수 있습니다. 손절·목표·내 선은 따로 표시합니다.
- 429·418 응답의 Retry-After를 따르며 모든 REST 경로에서 공통 대기합니다. 헤더가 없으면 429는 최소 60초부터 지수 대기, 418은 최소 15분을 사용합니다. 실제 IP 차단을 유발해서 테스트하지 않습니다.
- 거래소 메타데이터는 공유·캐시하고 가격 소수점은 가격 크기가 아니라 tickSize에서 구합니다.

## 저장과 알림 범위

기존 `omni-*` 관심 종목·수평선·가격 알림 저장 키를 이어서 사용합니다. 레이어와 Auto는 새 버전 설정으로 저장합니다.
기기와 브라우저별 저장이며 계좌 금액·위험률·레버리지 입력 카드는 제거했습니다.
동시 가격 알림·동시 신호는 하나의 메시지에 모두 묶고, 페이지 안의 알림 기록에 최근 50개 메시지를 남깁니다. 신호 기록 날짜는 연도를 포함합니다.
사용자 요청에 따라 시스템 알림·백그라운드 알림은 보류했습니다. 가격 알림은 현재 종목을 보고 있는 실행 중 페이지 안에서만 표시·소리가 나며, 탭 종료·절전 중 감시를 보장하지 않습니다.

## 파일과 라이선스

- `core.js`: 확정 봉 분석·주봉 집계·시각 및 Auto 범위 계산
- `boot.js`: 구성 파일 로딩 실패 안내·새로고침 복구
- `market.js`: 선물 공개 REST·선택 세대/소켓 격리
- `app-state.js`, `chart-render.js`, `app.js`, `styles.css`: 상태·차트·UI
- `tests/regression.test.cjs`: 네트워크 지연·실패와 데이터/범위 회귀 검증
- `tests/shock.test.cjs`: 급변동·반등 판정과 RSI·볼린저 검증
- `manifest.webmanifest`, `icon*.png`, `icon.svg`: 홈 화면 설치용 (서비스 워커·오프라인 캐시 없음)
- `vendor/`: TradingView Lightweight Charts 4.2.0 (Apache-2.0). LICENSE, NOTICE 및 차트 내 TradingView 저작자 표시를 유지합니다.

공식 API: [Binance USD-M Futures](https://developers.binance.com/docs/derivatives/usds-margined-futures/market-data/rest-api/Mark-Price), [Lightweight Charts 4.2](https://tradingview.github.io/lightweight-charts/docs/4.2/).
