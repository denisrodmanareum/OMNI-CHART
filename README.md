# OMNI 차트

바이낸스 USDT 무기한 선물 시세로 OMNI 신호와 구조선을 보여주는 웹 차트입니다. 빌드 없이 `index.html` 한 파일로 동작합니다.

**참고 정보입니다. 자동 주문을 하지 않으며 수익을 보장하지 않습니다.** 지금까지의 백테스트에서 통계적으로 입증된 조합은 없었습니다.

## 실행

```bash
python -m http.server 8765
```

브라우저에서 `http://localhost:8765`를 엽니다. 시세와 실시간 캔들은 브라우저가 바이낸스 공개 API에서 직접 받습니다. 선물 접속이 안 되면 현물 시세로 대신합니다.

## 기능

- 바이낸스 USDT 무기한 전 종목 검색 (24시간 거래대금 순), 15분·1시간·4시간·일봉·주봉
- 신호: 일봉 모멘텀 전환, 4H 일목 전환선·기준선 교차 (봉 마감 확정값, 손절 2×ATR·최대 10%, 익절 2R, 최대 72시간, 같은 시각 반대 신호는 WAIT)
- SQ: 4H 볼린저가 켈트너 안에서 풀리고 종가가 SMA20 위면 진입, SMA20 이하 마감이면 청산
- 구조: 지지·저항 (강한 레벨 실선, 1회 레벨 점선), 단기·장기 추세선과 이탈, 1D·1W 레벨, 피보나치 0.5·0.618, 반등·반락 후보 구간
- EMA 20·50·200, 거래량, 마우스를 올린 봉의 시가·고가·저가·종가
- 수평선 그리기, 가격 알림 (소리 · 브라우저 알림), 관심 종목 감시판, 수량·예상 청산가 계산
- 최근 신호 결과표 (손절 -1R, 익절 +2R, 만료·교체는 그 시가 기준, 수수료 제외)

수평선, 알림, 관심 종목, 레이어 설정은 브라우저 저장소에 남으므로 기기마다 따로 저장됩니다. 가격 알림은 페이지가 열려 있을 때만 동작합니다.
